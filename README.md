# Web1 Sapir

A static web project created as part of a web development course/project at Sapir College.

## Overview

This project is a standalone HTML/CSS website. It includes a main page, custom styling, product/item images, background images, and social-media assets. The site is designed to demonstrate fundamental front-end web development concepts using HTML and CSS without a server-side application or build system.

## Technologies

- HTML5
- CSS3
- JPG and PNG image assets

## How to Run

No installation or build step is required.

1. Extract the project ZIP file.
2. Open the `web 1` folder.
3. Open `index.html` in a modern web browser such as Chrome, Edge, or Firefox.

The website should load locally using the files included in the project.

## Main Files

### `index.html`
Contains the structure and content of the website.

### `index.css`
Contains the visual styling, layout, typography, spacing, backgrounds, and other presentation rules used by the website.

### `backgroud-box/`
Contains background images used by the website.

### `items/`
Contains the item/product images displayed by the website.

### `social/`
Contains image assets used for social-media or promotional sections.

## Notes

- This is a static front-end project.
- The project does not require Node.js, a database, or a web server for basic use.
- Keep the relative folder structure unchanged so that image and stylesheet paths continue to work correctly.
- The folder name `backgroud-box` is retained as provided by the original project.

## Browser Compatibility

The project is intended to run in modern desktop browsers, including:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

## Development

To modify the website, edit `index.html` for page content and `index.css` for styling. Image assets can be replaced or added in the corresponding asset folders, provided that the paths referenced by the HTML/CSS files are kept consistent.
